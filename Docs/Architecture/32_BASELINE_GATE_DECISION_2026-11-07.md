Переход `17 → 15 → 0` подтверждает **зависимость количества smoke-test ошибок UE Core от языка/локали**. Исходники `RunSmokeTests`, `LowLevelTestAdapter`, `FStructuredLogFormatTest`, `FUnifiedErrorTest` объясняют механизм. Две проверки Float/Double правдоподобно совпадают с [Epic UE-305638](https://issues.unrealengine.com/issue/UE-305638); **точные 15 assertions не атрибутированы**, поэтому не утверждать, что все ошибки были именно UE-305638 или что каждый прежний failure доказанно безвреден.

## Исключения и принятый риск

1. **Ранние аварии диагностических запусков:** `EXCEPTION_ACCESS_VIOLATION` в `UnrealEditor-Core`, причина не расшифрована (отсутствуют соответствующие PDB/отладчик). Последующий **обычный** интерактивный запуск без специальных флагов прошёл. Риск не закрыт, но сейчас нет доказанной связи с игровыми системами. Возврат к расследованию при воспроизводимом обычном сбое.
2. **ZenServer/EditorLayout:** прежние предупреждения остались; отдельные риски окружения/кеша и интерфейса. Успешной инициализации последнего запуска не препятствовали; не считать устранёнными.
3. **UE Core assertions:** локализационная зависимость подтверждена поведением; конкретное сопоставление всех 15 прежних `CHECK` отсутствует. Необходимая для строгого аудита полная атрибуция остаётся открытой.
4. **Полная машинная приёмка:** новый automated UE compile/PIE на чистом final baseline, Windows package, migration и полноценная регрессия не выполнялись; предоставленные пользователем результаты маркировать USER-VERIFIED, прошлые отчёты не переписывать.
5. **Инструментальная среда:** включение Unreal MCP процессными флагами не изменяло tracked `.uproject`/`.ini`, но полностью идентичным запуску без дополнительных модулей автоматически не считается.

**Условия отмены исключения / эскалации:** устойчивый краш при обычном запуске, новые Error/Fatal при English/English, регрессия пользовательских сценариев или обнаруженные сбои сборки/сохранения должны вновь блокировать соответствующий срез и запускать адресную диагностику. Не скрывать эти ограничения в релизной приёмке.
