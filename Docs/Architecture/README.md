## Основные решения

- Первый этап — одиночная настольная игра на Blueprints. Сетевой режим, боевую систему и сложную симуляцию экосистемы в этот план не включаем.
- Новые системы размещать в `/Game/Survival`, оставив существующие карты в `/Game/Content/Survival/Maps`. Не переносить старые ресурсы массово.
- Начать с тестовой карты и цепочки «подобрать ресурс → увидеть в инвентаре → создать предмет → поставить фундамент → сохранить и загрузить».
- Инвентарь — единственный владелец количества предметов. Крафт, строительство и UI запрашивают операции, но не редактируют массив слотов напрямую.
- Сначала подтвердить активные Blueprint-классы, зависимости Water и поведение плавания. Декоративные деревья и камни не считать готовыми источниками ресурсов.
