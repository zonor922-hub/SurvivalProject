# Восстановление SurvivalProject — снимок A02

Дата снимка: 25.10.2026. Движок: Unreal Engine 5.8.4.

В этой папке должны находиться:

- `SurvivalProject/` — независимая копия исходных файлов проекта;
- `SHA256_MANIFEST.json` — размеры и SHA-256 всех 779 исходных файлов;
- `verify_backup.py` — проверка копии без изменения файлов;
- эта инструкция.

## Проверка копии

Если установлен Python, открой терминал в этой папке и выполни:

```powershell
python verify_backup.py
```

Успешный результат: `Files checked: 779`, `Hash mismatches / missing: 0`.
Первичная проверка снимка уже выполнена при A02. При переносе на другой диск проверку следует повторить.

## Открытие восстановленного проекта

1. Скопируй весь каталог `SurvivalProject` из снимка в новую отсутствующую папку, например `<PROJECT_ROOT>_Restored_A02`.
2. Открой `.uproject` из новой папки движком UE 5.8.4.
3. Открой карту `/Game/Content/Survival/Maps/LV_Survival_Nature`. На диске это `Content/Content/Survival/Maps/LV_Survival_Nature.umap`.
4. Проверь окружение и озеро. На снимке в карте 296 акторов: в частности 1 Landscape, 1 WaterBodyLake, 1 WaterZone и 257 PhysicsVolume.
5. Продолжай работу в явно выбранной восстановленной папке только после проверки; исходный проект не перезаписывай.

Стартовая карта в конфигурации снимка всё ещё Third Person, поэтому выбор Nature вручную необходим. Saved/Intermediate/DerivedDataCache исключены из снимка и создаются движком заново. Первая загрузка может занять время из-за построения кэшей и шейдеров.
