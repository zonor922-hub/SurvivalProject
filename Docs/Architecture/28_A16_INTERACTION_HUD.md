## Реализация по опубликованному PR

- Добавлен `WBP_HUD`, подключён к `BP_SurvivalPlayerController`.
- Используются focus events существующего `BPC_Interaction` и существующая система World Pickup.
- HUD показывает interaction prompt при наведении на доступную цель; при потере focus prompt скрывается.
- Недоступное действие показывает disabled reason; при `PickupInProgress = true` проверена резервная причина «Взаимодействие недоступно».
- Отображаются сообщения об успешном и неуспешном взаимодействии, включая отказ inventory.
- Результат автоматически исчезает примерно через 3 секунды.

По описанию PR №23 в него также вошли проверенные изменения `BP_WorldPickup` и `LV_SystemsTest`. DOC01 эти ресурсы не изменяет. Полная независимая инспекция бинарных графов по этим описаниям не заявляется.
