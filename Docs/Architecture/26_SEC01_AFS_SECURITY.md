# SEC01 — отключение неиспользуемого Android File Server

Дата: 02.11.2026. База: `main`, `aa8f7dbd25bf707a30722feee809794d61fcfbf8`.
Ветка: `security/sec01-disable-afs`. Статус: READY для ручного рассмотрения Draft PR; не объединено.

## Причина и область изменения

Проект разрабатывается для Windows на Unreal Engine 5.8.4. Android File Server (AFS) сейчас не требуется. В публичной конфигурации находилось значение SecurityToken; его значение здесь не приводится.

В секции `[/Script/AndroidFileServerEditor.AndroidFileServerRuntimeSettings]` файла `Config/DefaultEngine.ini`:

- `bEnablePlugin=False`;
- `bAllowNetworkConnection=False`;
- строка `SecurityToken` удалена.

Сохранены `bIncludeInShipping=False`, `bAllowExternalStartInShipping=False`, `ConnectionType=USBOnly` и все остальные параметры. Другие секции, окончания строк, Blueprint, карты, игровой код и существующие результаты тестов не менялись. Зависимости SEC01: актуальная конфигурация AFS; игровых зависимостей нет.

Изменённые файлы: `Config/DefaultEngine.ini`, этот отчёт и краткая запись SEC01 в `Docs/ProjectStatus.md` согласно AGENTS.md.
