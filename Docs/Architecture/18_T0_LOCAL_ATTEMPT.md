## Конкретный блокер управления

Windows computer-use находит окна и выполняет обычные действия, включая дублирование и ввод имени. Однако всплывающее меню выбора типа параметра закрывается при следующем автоматизированном вводе. Наблюдалось и при `type_text`, и при `press_key`; попытка нажать поле поиска с адресацией по отдельному screenshot меню попала в элемент под закрывшимся меню. В списке доступных окон меню не имеет отдельной выбираемой записи. Дерево accessibility окна Blueprint содержит только корневое окно, без элементов графа и параметров. Без надёжной адресации нельзя подтвердить правильный тип Other и собрать требуемые графы безопасным способом.

Проверены доступные объявления BlueprintEditorLibrary установленного UE; подтверждённый обход для построения полного тестового графа не найден. Вызов компилятора без проверяемого графа не использовался как замена T0.

Для продолжения нужен работающий ввод во всплывающие меню Unreal через computer-use либо ручная сборка временных графов: Other типа собственного тестового класса, чтение/запись private Slots, вызов private-функции с подключённым выходом и отдельные три внешние попытки. Затем нужны реальные результаты компиляции и повторная проверка очистки. Изменение архитектуры для этого не выполнялось.

## Очистка и ошибка редактора

Запрос dirty-пакетов через встроенную Python-консоль Unreal показал только тестовую копию. `EditorAssetLibrary.delete_asset` для неё вернул `False`: Unreal сообщил, что Blueprint используется, и зарегистрировал ensure в ObjectTools.cpp:4045. Это ошибка очистки, не ошибка компиляции T0. Редактор продолжил работать.

Для окончательной очистки изолированный редактор штатно закрыт. Диалог «Сохранять контент» содержал единственный `BPC_Inventory_T0_TEMP`; выбрано **«Не сохранять»**. В логе есть `LogExit: Exiting` и закрытие файла журнала. Процесс UnrealEditor после этого отсутствует. Несохранённая фикстура удалена завершением процесса; файлов TEMP в Content и Saved не найдено. UE в конце этой попытки закрыт.
