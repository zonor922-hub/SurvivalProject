## Структура и происхождение

`Architecture/` содержит копии существующей документации; `Architecture/evidence/` — отобранные результаты проверок и два проверочных сценария; `Architecture/versioning/` — инструкцию восстановления, проверяющий скрипт и шаблоны Git/LFS. Исходные локальные документы сохранены без изменений. Публикуемые копии обезличены; хеши оригиналов и копий могут отличаться.

Отчёты описывают состояние на момент соответствующей задачи. Утверждения об отсутствии remote, чистом рабочем дереве и следующей задаче являются историческими. Для актуального состояния используйте ProjectStatus.md. Скрипты проверок не запускались при публикации документации; упомянутые в отчётах генераторы и диагностические пробы остаются локальными.

`<PROJECT_ROOT>` — корень рабочего клона с SurvivalProject.uproject; `<PROJECT_PARENT>` — его родитель; `<LOCAL_WORKSPACE>` — локальная папка исходных отчётов, инструментов и копий; `<USER_HOME>` — домашняя папка. Перед выполнением исторических примеров замените обозначения фактическими путями. Резервные копии A02 и их служебные файлы остаются локальными; скрипт verify_backup.py запускается рядом с реальным снимком и его SHA256_MANIFEST.json, а не в Docs.

Архивы, игровые ресурсы, Saved/Intermediate/DerivedDataCache, полные журналы, временные диагностические пробы и личные настройки в документацию не включены. JSON результатов не подтверждают заново прохождение проверок и не заменяют бинарные Unreal assets. Для анализа Blueprints в ChatGPT используйте текстовые отчёты.

## Обновление прогресса

После задачи обновляйте ProjectStatus.md и соответствующий отчёт: ID, результат, проверка, ограничения, commit. План A01–A44 задаёт объём работ, но не является автоматическим разрешением на реализацию всех задач. Сохраняйте проверенные изменения отдельным коммитом и отправляйте их в GitHub. Перед отправкой просматривайте diff и добавляйте явные пути.
