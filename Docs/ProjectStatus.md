## Подключение и сохранение

- Приватный GitHub-репозиторий создан; origin настроен на него. Игровая версия A04 опубликована; чтение файлов через GitHub-подключение подтверждено. Подключению предоставлены права pull/push.
- В репозитории действуют .gitignore и .gitattributes для Git LFS. Историческая проверка восстановления A02 была локальной; полная загрузка LFS из GitHub при публикации документации заново не проверялась.
- Доступ именно из обычного чата ChatGPT требует проверки в том чате: прочитать SurvivalProject.uproject через подключённый GitHub. Наличие подключения здесь не подтверждает доступность во всех режимах ChatGPT.
- Документация хранится в Docs; этот файл — единственный основной файл текущего прогресса. A05–A07/A24 опубликованы в main, A08 проверена в отдельной ветке; результаты находятся рядом с отчётами. Старый a05_types_created.json — только историческая запись первоначального создания, не итоговая проверка.

Рассмотреть PR A08; следующая задача A09 выполняется на проверенной A08 отдельной веткой. Старые main/backup и шесть неопубликованных коммитов сохранены. В публикуемой истории нет незавершённых checkpoint. Не отправлять исходную main или backup.

Собственный GameInstance подключён; глобальный GameMode остаётся ThirdPerson. В LV_SystemsTest назначен BP_SurvivalGameMode.
