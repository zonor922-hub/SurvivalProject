## Подключение и сохранение

- Приватный GitHub-репозиторий создан; origin настроен на него. Игровая версия A04 опубликована; чтение файлов через GitHub-подключение подтверждено. Подключению предоставлены права pull/push.
- В репозитории действуют .gitignore и .gitattributes для Git LFS. Историческая проверка восстановления A02 была локальной; полная загрузка LFS из GitHub при публикации документации заново не проверялась.
- Доступ именно из обычного чата ChatGPT требует проверки в том чате: прочитать SurvivalProject.uproject через подключённый GitHub. Наличие подключения здесь не подтверждает доступность во всех режимах ChatGPT.
- Документация хранится в Docs. Исходные локальные отчёты сохранены. Шесть незакоммиченных типов A05 не входят в коммит документации.

## Следующий шаг и ограничения

Завершить проверку A05 по критериям плана, составить итоговый отчёт и сохранить проверенные assets отдельным коммитом. Проверки A05 и реализация механик не входят в публикацию документации.

Собственный GameInstance подключён; глобальный GameMode остаётся ThirdPerson. В LV_SystemsTest назначен BP_SurvivalGameMode. Производственная карта не переключена. Инвентарь, крафт, строительство, сохранение и прочие системы остаются планом, если их реализация не подтверждена отдельным отчётом. Windows packaged build и полноценная игровая проверка плавания остаются открытыми проверками по существующей документации.

При переносе исторических документов сохранены прежние формулировки статуса; они не отменяют эту сводку. Текущие assets и игровые настройки в коммите документации не изменяются.
